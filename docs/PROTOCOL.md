# Work protocol

The prototype processes real halfpipe video and finds candidate jumps automatically. It uses body landmarks to estimate the hip position and fits a local blue lip in each sampled frame. A desktop window shows marked images, a timeline, and review controls. Results can be corrected, excluded, saved, and exported. Tests cover the measurement formula, jump grouping, partial sessions, and review actions. Real footage was also processed. Heights stay in pixels unless a suitable scale is supplied. The main open tasks are better athlete tracking, labelled validation, and camera calibration for reliable physical heights.
