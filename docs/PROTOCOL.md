# Prototype-2 work protocol

The first prototype uses Python to measure a selected halfpipe jump frame. It opens a video and lets the user move between frames. The user marks two points on the blue line and one point at the athlete's hip. The program calculates the vertical gap in pixels and can show a rough metre estimate when a valid scale is known. Selected jumps can be saved to CSV. The code is documented and the measurement formula has automated checks. The next step is to compare results with known heights before adding automatic tracking.
