# Work protocol

This prototype reads real halfpipe video and finds jump candidates from hip landmarks, blue-lip detection, and motion tracking. Magnified moving regions help separate riders from spectators. Takeoff checks reject initial drops, and candidates are grouped into riding sequences. The desktop app shows peak images and supports corrections, saved sessions, and CSV export. Supplied pipe dimensions are recorded. Metre estimates require a suitable visible reference at the rider's depth. Geometry, grouping, file handling, and review controls were tested. Real footage was processed. Remaining tasks are labelled validation, stronger lip detection, and camera calibration.
